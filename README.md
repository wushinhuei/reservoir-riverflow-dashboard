# 水庫觀測河川流量數據分層分析

這個資料夾可直接上傳到 GitHub repository，並用 GitHub Pages 發布。

## 檔案說明

- `index.html`：可直接開啟的網頁主檔。
- `data/reservoir_data.json`：網頁使用的原始資料 JSON。
- `data/reservoir_data.js`：同一份資料的 JavaScript 版本，供網頁或其他前端程式使用。

`index.html` 已內嵌目前資料，可以單獨運作；`data` 資料夾是為了讓 GitHub 上也同步保留網頁使用的資料內容，方便查閱、下載或後續改成外部資料讀取。

## GitHub Pages 建議

1. 建立一個 GitHub repository。
2. 將本資料夾內的所有檔案上傳到 repository 根目錄。
3. 在 repository 的 `Settings` -> `Pages` 啟用 GitHub Pages。
4. 發布後，GitHub Pages 會以 `index.html` 作為首頁。
